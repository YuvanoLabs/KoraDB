# Support

KoraDB v1.0.0 is a Community general-availability product. There is no
production SLA, guaranteed response time, or private implementation support.

## Where to ask

| Need | Channel |
|---|---|
| Reproducible product defect | Bug report issue form |
| Product or API proposal | Feature request issue form |
| Usage question | GitHub Discussions after the public repository enables it |
| Security vulnerability | Private process in [SECURITY.md](SECURITY.md) |
| Conduct concern | [smartbytecoder@gmail.com](mailto:smartbytecoder@gmail.com) |

Search documentation and existing issues before posting. Include KoraDB
version, operating system, deployment mode, a minimal reproduction, expected
behavior, actual behavior, and redacted diagnostics.

## Support boundaries

Maintainers can help with documented KoraDB behavior and supported release
artifacts. They cannot debug proprietary application logic, unreviewed public
internet deployments, customer data, infrastructure outages, or forks. Backup
retention, host encryption, certificate lifecycle, monitoring, and recovery
drills remain operator responsibilities until an explicit support offering is
published.

General support answers are best-effort. Future contracted support may add
defined coverage, but security fixes will not be withheld to force an upgrade.
