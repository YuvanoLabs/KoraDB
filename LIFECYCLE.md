# KoraDB release lifecycle

KoraDB v1.0.0 begins the **Community GA** lifecycle. It is a single-node
release with the documented product boundaries; it does not create a production
SLA or regulated-workload certification.

KoraDB will publish a versioning, compatibility, support-window, deprecation,
and security-maintenance policy for subsequent maintained lines, backed by the
evidence in [docs/PRODUCTION_RELEASE_PLAN.md](docs/PRODUCTION_RELEASE_PLAN.md).

For every published release, maintainers will provide release notes, checksums,
SBOM/provenance evidence, and an upgrade/rollback statement. Security fixes are
coordinated through [SECURITY.md](SECURITY.md). End-of-life dates are not set
until a supported release line exists; they will be announced in release notes
before a line is retired.
